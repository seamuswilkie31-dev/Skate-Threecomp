# Source-scale neighborhood skating

Select your ISO in the launcher, open the skating prototype, then click **Skate neighborhood**. It loads seven selected Downtown batches at their original vertex spacing. The viewport uses the new Rust movement, input, camera, and renderer on that geometry. This is an early gameplay slice; original Skate 3 movement, characters, missions, animation, lighting, streaming, and saves are not reconstructed.

Use W/S to push/brake, A/D to steer, Space to ollie, F to flip, and Q/E to spin. Controller controls remain stick steering, A push, B brake, X ollie, Y flip, LB/RB spin. R or Start restarts the source route and clears prototype statistics. **Source start** does the same. **Test course** returns to the original course. **Rail practice** is available there; source mode contains no authored practice rails. Mode-changing controls are disabled while a scene load is pending.

The source placement has scale 1.0 and only recenters/translates coordinates. Speed is displayed in source units per second rather than km/h, because the original world-unit calibration and physics tuning remain unverified. The fixed research start is native board position approximately `(512.82666, 84.623, 88.72301)`, facing +Z. It is verified against a broad shallow surface, including a headroom query; it is not an original game's spawn record. An explicit test rides more than 20 source units continuously on source triangles and crosses a cell border before completing an ollie/landing.

Only imported triangles supply support in this mode. The test-course floor, ramps, boundary markers, and rails are hidden and inactive. Missing geometry stays a gap. Horizontal movement stops at the loaded geometry's XZ bounds and uses the existing wall probes. Falling 20 units below the lowest loaded geometry, leaving the bounds unexpectedly, or producing a non-finite position returns the rider to the verified start. Recovery clears an unbanked chain and transient movement/flip/grind state while preserving banked points and completed-contact statistics. Manual reset starts fresh. Scores and tricks remain in memory and are not written to original game saves.

This remains point support with horizontal body probes rather than full board/body rigid-body collision. Roof/ceiling interaction during movement, wall sliding, moving objects, original collision-format rules, and game-data rails remain pending. Some render surfaces may be collidable even when the original game treated them differently. Missing batches and objects remain visible gaps. Current textures cover 54 meshes; 56 use a plain fallback. See [selected assets and verification](NEIGHBORHOOD.md).
